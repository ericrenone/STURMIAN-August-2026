## PART I: THEORETICAL FOUNDATIONS OF STURMIAN DYNAMICS

### I.1 Sturmian Sequences as the Canonical Aperiodic Code

A Sturmian sequence is an infinite binary string with the following properties:

1. **Deterministic:** Each symbol is computed from a rotation number α (typically irrational)
   - S_α(n) = ⌊(n+1)α⌋ − ⌊nα⌋ (Beatty sequence / Three-Distance Theorem)

2. **Aperiodic:** No period p exists such that S(n+p) = S(n) for all n

3. **Minimal Complexity:** The number of distinct n-length substrings = n+1 (minimum possible for aperiodic sequence)

4. **Golden Ratio Optimality:** When α = φ − 1 = 1/φ ≈ 0.618, the sequence exhibits maximum structure with minimum redundancy

5. **Fibonacci Structure:** The Sturmian sequence with α = φ − 1 is the Fibonacci word, with letter frequencies converging to (φ − 1, 2 − φ) = (0.618, 0.382)

### I.2 The Sturmian-to-Quasicrystal Map

Every Sturmian sequence with rotation number α projects onto a 1D quasicrystal via the de Bruijn cut-and-project:

**De Bruijn Construction:**
1. Embed ℝ in ℝ² as the diagonal y = αx
2. Tile ℝ² with unit squares (integers × integers)
3. Select squares whose intersection with y = αx has non-empty interior
4. Project to the x-axis
5. Result: A 1D aperiodic tiling (quasicrystal)

**Symbolic Dynamics:**
- Each tile in the quasicrystal (gap length) encodes a symbol (0 or 1)
- The resulting sequence of symbols is Sturmian with rotation number α
